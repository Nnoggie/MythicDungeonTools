## 6.2.0-alpha3 (2026-07-21)

- Added initial WoW 12.1 PTR support for Midnight Season 2. Enemy positions constantly change on the PTR. Please report any issues you find in discord!
- Added an option to show each pull's total health in the route sidebar (off by default).
- Added an option to automatically pan the map to the selected pull (on by default).
- Enemies can now be dragged on the map to move them in and out of pulls, with a preview showing which enemies will move.
- New route export strings now use Blizzard's native encoding. Existing route strings still import, but new strings require an updated addon version to import.
